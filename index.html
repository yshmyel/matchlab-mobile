About MatchLab

Feeds refresh about every 30 minutes through GitHub Actions. This screen checks for a new feed every five minutes. Game times use your device timezone; date filtering uses Pacific time.

ESPN is an unofficial data source. A missing halftime score stays unknown. The Models tab shows provisional fitted estimates and held-out evaluations. Available full-game NBA reference odds are labelled by bookmaker and retrieval time. Soccer 1H and player N+ prices remain unavailable unless separately verified. The app never places bets.
